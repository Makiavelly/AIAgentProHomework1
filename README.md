## Запуск parse_fresh.py

Запускать команды нужно из папки проекта:

```powershell
python parse_fresh.py --generate       # сгенерировать вопросы
python parse_fresh.py --answer         # получить ответы без тулзов
python parse_fresh.py --answer-intro   # получить ответы с поиском трех интро Wikipedia
python parse_fresh.py --answer-tools   # получить ответы с поиском интро и строк в полных статьях
```

По умолчанию используется `openai/gpt-4o-mini`. Другую модель можно указать через `--model`:

```powershell
python parse_fresh.py --answer-tools --model "anthropic/claude-sonnet-4.6"
```

Несколько режимов можно запустить одной командой:

```powershell
python parse_fresh.py --generate --answer-tools
```

Список всех параметров:

```powershell
python parse_fresh.py --help
```
